Chamber Devices

Every phone, tablet, and laptop here carries the whole chamber. Pair two of them with a picture code — a string of emoji you can send in any chat — and they trade everything they know, no server needed.

The promise: if any one device survives, the whole record survives.

Picture codes

Pair with a cousin's device

With the family relay set up, devices on this page find each other by themselves — nothing to do. Picture codes are for pairing with no server at all: copy the emoji, send them in any chat, and the two browsers connect directly. Check the little match badge (four pictures) together — same pictures on both screens means it's really you two.

Custody of the record

Save it, share it, start over

💾 Save the record

One file holds every vote, bill, and status ever recorded. Tuck it somewhere safe — it can rebuild everything.

📂 Load a record

Merge a saved file into this device. Nothing doubles up — only genuinely new history lands.

🧹 Wipe this device

Only this device forgets. Every other copy keeps the record, and this one can rejoin and catch up later.

The recovery guarantee, spelled out. The chamber's history is an append-only log and every device holds all of it. A brand-new browser that pairs with any single up-to-date cousin — by relay, picture code, or a saved file — receives the complete record and rebuilds the identical chamber. There is no main copy to lose.
